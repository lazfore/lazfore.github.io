## 1. HELIX: Model-Harness Co-evolution for Recursive Self-Improvement

* **类型 / 来源：** 新论文 + 新代码仓库｜arXiv / GitHub
* **作者 / 维护者：** Tianyu Fan、Chao Huang；HKUDS
* **日期：** 2026-08-14
* **链接：** [论文](https://arxiv.org/abs/2608.13951) · [代码](https://github.com/HKUDS/HELIX)
* **核心内容：** HELIX 将 agent system 分解为 typed ports、atoms、recipes、product shells 与 runtime policies，使 harness 干预可追踪、可组合并保留轨迹与 provenance。一次 code-repair 演化实验搜索 65 个候选，最佳固定 harness 相对 Pi 增加 4.0% task coverage；候选组合带来最多 58.0% 的额外 verified coverage，并从 200 个 sibling slots 生成 438 条可训练记录。
* **与你的方向关系：** 这是 Harness Optimization 与 executable harness learning 的直接相关工作，尤其值得和“从极简 scaffold 自然增长”的路线比较：HELIX 的搜索空间由来自四个现有 harness 的 1,332 个 atoms 和 96 个标准接口构成，更强调可审计重组与 model–data feedback loop。
* **建议：** **精读**。重点比较其受约束的模块重组与开放式函数增长在搜索偏置、intervention identity、回归检测和训练数据构造上的差异。

## 2. Demystifying Agent Skills: Why They Work—Until They Don't

* **类型 / 来源：** 新论文｜arXiv
* **作者 / 维护者：** Zhiyuan Jiang、Fangrui Huang、Hanwen Xing 等
* **日期：** 2026-08-14
* **链接：** [论文](https://arxiv.org/abs/2608.14036)
* **核心内容：** 论文通过跨 benchmark、agent harness 与 LLM 的受控实验，以及 8,135 条 trial record 和配对轨迹分析，将 skill 的作用归纳为三类、十二种使用模式。匹配实验中 skill 比 Workflow Memory 高 6.06 分，65.7% 的案例主要依靠 procedural anchoring；当 skill pool 从 5 增至 100 时，actual-use precision 从 29.6% 降至 3.3%，说明 retrieval 会迅速成为瓶颈。
* **与你的方向关系：** 它为 persistent instruction、code-as-memory 与 self-evolving skills 提供了比总成功率更细的因果解释，也提示自动增长的 skill/harness 必须同时控制检索拥塞、上下文兼容性和陈旧假设。
* **建议：** **精读**。建议把十二种 skill-use mode、procedural anchoring 比例与 retrieval scaling 曲线纳入 harness memory 设计及消融实验。

## 3. P2Skill: Privacy Preserving Skill Distillation for Cloud-Local LLM Inference Systems

* **类型 / 来源：** 新论文｜arXiv
* **作者 / 维护者：** Myunghoon Ryu、Geunpyo Park、Sungjoon Lee、XinYu Piao、Jong-Kook Kim
* **日期：** 2026-08-14
* **链接：** [论文](https://arxiv.org/abs/2608.14094)
* **核心内容：** P2Skill 让本地小模型按照可迭代 refinement 的 skill prompts 完成任务分解、PII-aware routing、paraphrasing 与结果重构，只把去除敏感信息后的子请求交给云端模型，不依赖隐私专用微调或额外检测器。作者在四域 benchmark 上报告，其 privacy-preserved inference quality 相对两类基线分别提升 1.69× 与 3.66×。
* **与你的方向关系：** 该工作把 semantic privacy 与 executable skill/harness optimization 连接起来：隐私边界不只是 entity masking，而是由本地 controller 决定信息如何分解、释放和重组。
* **建议：** **精读**。重点验证 PII routing 的漏检威胁模型、paraphrase 后的语义泄漏，以及由云端模型迭代 skill 是否会引入新的持久化指令风险。

## 4. AgentRewind: Recoverable Execution for Long-Horizon LLM Agents

* **类型 / 来源：** 新论文｜arXiv
* **作者 / 维护者：** Yu Zhuang、Kefei Chen、Yitong Duan、Shuxin Zheng、Jian Li、Xu-Yao Zhang
* **日期：** 2026-08-14
* **链接：** [论文](https://arxiv.org/abs/2608.14380)
* **核心内容：** AgentRewind 同步记录 agent context 与受控环境的 checkpoint，使长程任务在错误扩散后可以回到早期状态，并携带上一轮尝试的信息重新执行。论文同时提出 MettleBench，以一组相互关联的工程需求评价最终完成率和部分进度；跨任务、模型、执行策略与 harness 的实验均显示其优于对照方法。
* **与你的方向关系：** 它将 recovery 作为 agent scaffold 的一等运行时能力，直接关联工具副作用控制、长程状态一致性和安全回滚；对可自修改 harness 而言，checkpoint 还可作为候选更新的 transaction boundary。
* **建议：** **精读**。重点关注 context 与 environment checkpoint 如何对齐、哪些外部副作用不可逆，以及恢复后如何避免再次走入同一失败轨迹。

## 5. Tripwire: Triggering Aligned Refusal via Statistically Certified Safety Neurons

* **类型 / 来源：** 新论文｜arXiv
* **作者 / 维护者：** Wei Zhao、Zhe Li、Peixin Zhang、Jun Sun
* **日期：** 2026-08-14
* **链接：** [论文](https://arxiv.org/abs/2608.14392)
* **核心内容：** Tripwire 通过带 false-discovery-rate 控制的逐神经元假设检验与 utility-specificity filter 识别安全专属神经元，再以 trigger-style clamp 激活模型已经学到的拒绝行为。作者给出 detector-gated inference intervention 与 offline bias-patch 两种等价部署方式；在四个安全对齐模型和四类攻击上，平均 ASR 降至不高于 2.0%，MT-Bench utility drop 为 0.5%–5.3%。
* **与你的方向关系：** 这是 jailbreak defense 的模型内部路线，可与 prompt/harness 层 guardrail 形成互补；其 gated intervention 也适合研究安全机制应放在模型、controller 还是 action gate 的哪一层。
* **建议：** **精读**。重点检查统计认证是否能跨分布、跨语言和自适应攻击保持有效，以及 detector 错误如何传导为拒绝缺失或过度拒绝。

## 6. AdsWorldEngine: A Self-Evolving Conversational Advertising Agent through Orchestrator and Tool Coevolution

* **类型 / 来源：** 新论文｜arXiv
* **作者 / 维护者：** Simiao Zuo、Chenhui Xu、Yimeng Jia、Qiang Lou、Jian Jiao、Denis Charles
* **日期：** 2026-08-13
* **链接：** [论文](https://arxiv.org/abs/2608.13833)
* **核心内容：** AdsWorldEngine 由 Opportunity Gate、Orchestrator、广告工具与 Evaluator 构成，先以 SFT 和 agentic RL 训练 orchestrator，再利用高低奖励 rollout 构造 preference data 反向训练工具，形成 actor–tool 共演化闭环。作者报告相对线上既有系统，离线 diversity 与 relevance 分别提升 60% 和 80%，线上 A/B test 的 RPM 与广告覆盖率分别提升 22% 和 74%。
* **与你的方向关系：** 虽然场景是广告系统，其“controller 产生轨迹—轨迹训练工具—新工具改变 controller 行为”的闭环是 executable harness learning 的重要相邻范式，并展示了成本敏感 judge 如何参与生产级优化。
* **建议：** **浏览**。重点抽取 actor–tool 交替更新、reward leakage 防控和线上指标 gate；领域本身与安全主题关联较弱，可不深挖广告建模细节。

## 7. Evaluating Agentic Learning Harness Capabilities Without Labels via the Scaling Hypothesis

* **类型 / 来源：** 新论文｜arXiv
* **作者 / 维护者：** Aryan Luthra、Kshitij Jain、Siddharth Arya、Bobby Filar、Anna Bertiger
* **日期：** 2026-08-11
* **链接：** [论文](https://arxiv.org/abs/2608.13608)
* **核心内容：** 论文针对安全运营中标签稀缺、陈旧且有偏的问题，让更强 teacher 稀疏提供纠正，并以带 continual-learning harness 的 student 向 teacher 收敛的程度估计 harness uplift。跨安全任务、模型家族与 harness 设计的结果显示 teacher-relative lift 与 held-out gold improvement 相关，而能力相近模型之间的 LLM-as-a-judge 不提供可用信号。
* **与你的方向关系：** 它直接回应 Harness Optimization 的 evaluator bottleneck：当在线反馈缺少可靠标签时，如何判断 memory/retrieval/controller 更新是真改进还是自我强化的假象。
* **建议：** **精读**。建议重点审查 teacher bias、稀疏纠正的采样机制和相关性强度，并与 held-out regression gate 的监督成本进行对照。

## 8. Handover of In-Context Learning State Across Session Boundaries

* **类型 / 来源：** 新论文｜arXiv
* **作者 / 维护者：** Masahiro Kato、Taka Kato
* **日期：** 2026-08-14
* **链接：** [论文](https://arxiv.org/abs/2608.14528)
* **核心内容：** 论文把跨 session 交接形式化为 task-relative ICL state 的传递，并区分逐字恢复旧材料与维持目标分布；在 exogeneity 条件下，predictive equivalence 刻画最粗粒度的确定性充分 handover 及其固定比特需求。作者提出三段式记录：精确保留决策和约束，以任务相关统计压缩重复证据，并保留统计量无法替代的原始观察。
* **与你的方向关系：** 该理论直接服务于 agent memory、context compaction 与多 Agent handoff，也为“哪些状态必须写入持久 memory、哪些可被摘要”提供了比经验式压缩更明确的语义标准。
* **建议：** **浏览**。值得收藏其 sufficient handover 定义和 memory–prediction error 边界，再判断这些假设能否扩展到有工具副作用和非平稳任务的 agent harness。

## 9. Repair, Not Improvement: Decomposing Constrained Decoding in Tool-Call Abstention

* **类型 / 来源：** 新论文｜arXiv
* **作者 / 维护者：** Janghoon Lee（Redrob）
* **日期：** 2026-08-14
* **链接：** [论文](https://arxiv.org/abs/2608.13959)
* **核心内容：** 论文用 byte-identical prompt 的三种解码条件，把 grammar 对 stop token 和可生成 token 集合的影响拆开，测量 0.6B–4B 开源模型在英语、韩语 tool-call abstention 上的行为。相对无约束解码，六个设置中四个 abstention 指标显著下降，最差为 −29.5 分；被“修复”的 698 个 abstention 中，545 个原本没有可读答案，说明约束主要修复格式而非判断质量。
* **与你的方向关系：** 这是 tool-use security 与 harness decoding policy 的关键负结果：schema enforcement 可能悄然删掉“不调用工具”这一安全动作，因此结构有效不等于 capability decision 正确。
* **建议：** **精读**。应把 abstention preservation 加入 tool router 和 constrained-decoding 的回归测试，尤其检查 stop-token 设计与多语言偏差。
