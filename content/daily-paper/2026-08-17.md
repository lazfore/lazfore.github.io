## 1. OpenClaw 2026.8.1-beta.2

* **类型 / 来源：** 项目重大更新｜GitHub
* **作者 / 维护者：** OpenClaw Foundation、Peter Steinberger 及社区维护者
* **日期：** 2026-08-15
* **链接：** [项目](https://github.com/openclaw/openclaw) · [发布说明](https://github.com/openclaw/openclaw/releases/tag/v2026.8.1-beta.2)
* **核心内容：** 该预发布版为共享 secret store 增加精确的 HTTPS 目标主机绑定，并在明文秘密离开进程前对未绑定替换执行 fail-closed；从任意可执行来源安装插件时，也要求显式 `--force` 确认并显示 provenance 警告。它还强化了 channel ingress 的 claim identity validation、macOS 多实例状态与 Keychain 隔离，以及 SQLite snapshot 的校验和“仅恢复到全新目标”约束。
* **与你的方向关系：** 这次更新直接覆盖 Agent Security 中的 secret exfiltration、capability / permission control 和插件供应链风险，也展示了 harness 如何在工具调用、插件安装、持久状态与恢复流程中建立可执行安全边界，而不是仅依赖提示词约束。
* **建议：** **精读**。优先检查 host binding 的匹配与绕过边界、sentinel substitution 的失败语义、插件可信来源分类，以及 beta 功能进入生产环境前需要补充的回归与攻击测试。
