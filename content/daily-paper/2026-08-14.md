## 1. ToolHazard: Scaling Adversarial Environments for Security Evaluation and Alignment of LLM-based Agents

* **类型 / 来源：** 新论文｜arXiv
* **作者 / 维护者：** Yutao Mou、Pengfei Yang、Zhe Yin、Zhangchi Xue、Xiaotian Luan等
* **日期：** 2026-08-12
* **链接：** [论文](https://arxiv.org/abs/2608.11878)
* **核心内容：** ToolHazard 用 Environment Simulator、Attacker Agent 和 User Simulator 自动构造可执行、有状态的工具环境，发现可行注入点、生成环境特定 payload，并形成长程任务。基于该框架生成的 ToolHazard-Bench 显示攻击时机与放置位置会显著影响 IPI 效果；生成的 alignment data 同时提升 ToolHazard-Bench 与 AgentDojo 上的安全性，并保持良性任务效用。
* **与你的方向关系：** 这是 Agent Security、tool-use security 与 indirect prompt injection 的直接工作，把安全评测从人工固定注入点推进到可扩展的 stateful environment synthesis，适合用于检验防御是否真正跨域、跨位置泛化。
* **建议：** **精读**。重点审查环境模拟器的真实性、攻击者与用户模拟器的闭环偏差，以及训练数据与两个评测集之间是否存在环境或攻击模板泄漏；论文仍标注为 Work in Progress。

## 2. AI4AI at Test-Time: Strong-to-Weak Capability Transfer via Harnesses

* **类型 / 来源：** 新论文｜arXiv
* **作者 / 维护者：** Cheng Qian、Wenting Zhao、Liangwei Yang、Heng Wang、Jielin Qiu、Heng Ji等
* **日期：** 2026-08-12
* **链接：** [论文](https://arxiv.org/abs/2608.12307)
* **核心内容：** 论文让强 builder model 使用 5% 数据作为验证集，多轮构造和改进弱 target model 的 inference-time harness，无需更新目标模型参数。在四个 Theory-of-Mind benchmark 上，平均性能从 0.49 提高到 0.91；增益主要来自把不稳定推理编译为确定性代码、任务路由和严格输出格式，而不是增加采样或推理长度。
* **与你的方向关系：** 该工作直接对应 Harness Optimization、executable harness learning 与“logic-to-code”能力迁移，也为从最小 scaffold 生长 harness 提供了强模型构建器基线和清晰的结构化增益来源。
* **建议：** **精读**。重点比较其 5% 验证集反复使用带来的过拟合风险、builder reasoning effort 与 harness 质量关系，以及确定性代码是否真正学习可迁移控制结构，还是编码 benchmark-specific shortcuts。

## 3. Agent Safety Should Be a Runtime Contract

* **类型 / 来源：** 新论文｜arXiv
* **作者 / 维护者：** Albus W. Ng、Yi Han、Jusheng Zhang、Wenhao Wang
* **日期：** 2026-08-11
* **链接：** [论文](https://arxiv.org/abs/2608.11274)
* **核心内容：** 论文主张以 harness 强制的 runtime contract 作为 Agent 安全单元：预防面用 sandbox、permission gate、filter 和 trajectory monitor 阻断危险动作，证据面则要求测试、日志、diff 与引用等可核验完成证据。作者结合 52 起公开事故、31 个无争议 false-completion 案例、12 个 Agent 系统的 trajectory schema 审计及 28,560 篇顶会论文标题审计，提出 Agent Trajectory Schema、Evidence Chain 与组合式 gate 命题。
* **与你的方向关系：** 与 capability / permission control、Agent Security 和安全 harness 设计高度一致，尤其强调“允许什么”与“如何证明正确完成”必须同时成为执行期约束，而不能只依靠 system prompt 或训练期对齐。
* **建议：** **精读**。它更接近有数据支撑的立场与研究议程，建议重点验证 incident sampling、false-completion 判定和组合监控命题，并将 preventive/evidential 双契约用于设计自己的 action gate 与 regression gate。

## 4. AI Guardrail Survival under Single-Cycle Agentic Self-Summarization

* **类型 / 来源：** 新论文｜arXiv
* **作者 / 维护者：** Ted Kwartler、Alan Aqrawi、Arian Abbasi
* **日期：** 2026-08-11
* **链接：** [论文](https://arxiv.org/abs/2608.11392)
* **核心内容：** 论文研究长时 Agent 在一次 self-summarization 后安全规则如何失效，指出“文本仍存在”不等于“行为上仍生效”。行为重放中，退化后的规则残留相较完整 welded rule 使违规率分别增加 34 和 57 个百分点；仅与外部 constraint registry 比较可发现规则缺失，却不能确认保留下来的规则是否仍会触发。
* **与你的方向关系：** 直接关联 persistent instruction security、context compaction 与 Agent memory 安全，说明压缩后的约束需要行为级 replay 或外部强制，而非关键词存在性检查。
* **建议：** **精读**。重点看规则焊接、压缩预算与 replay protocol，并注意结论只覆盖单次压缩；可进一步扩展到多轮压缩、跨模型摘要与 capability revocation 的生命周期测试。

## 5. Towards the Harness of Embodied Agents

* **类型 / 来源：** 新论文 + 新代码仓库｜arXiv / GitHub
* **作者 / 维护者：** Qi Wang、Tianyi Wang、Chengyang Li、Shikun Ban、Yurun Chen、Yizhong Ge等
* **日期：** 2026-08-03
* **链接：** [论文](https://arxiv.org/abs/2608.11246) · [代码](https://github.com/EIT-HAI/Thea)
* **核心内容：** Thea 将 coding-agent harness 迁移到具身任务，用 Agent loop 编排可调用的机器人能力，并以 Scene Graph as Context 提供持久符号世界状态，以 Evaluation as Exit Codes 判断动作终止、成功与失败原因。官方仓库已包含 provider-neutral harness、simulation 接口、机器人 port template、工具/技能/记忆与安全模块、安装脚本和文档，而非只有 README。
* **与你的方向关系：** 它扩展了 Harness Optimization 的应用边界，并把 refreshed world state、post-condition evaluator 与低层安全控制明确分离；对 tool-use security 和“可执行控制器应承担哪些职责”也有直接启发。
* **建议：** **精读论文，浏览代码**。重点比较 Scene Graph、exit-code evaluator 与软件 Agent 的 trace/state abstraction，并检查真实机器人部署中 model-level gate 与 emergency stop、碰撞避免等独立控制之间的隔离边界。

## 6. EvoGraph-Mem: Failure-Aware Editable Graph Memory for Long-Term Language Agents

* **类型 / 来源：** 新论文｜arXiv
* **作者 / 维护者：** Yuxi Qian、Yuxiang Ren
* **日期：** 2026-08-03
* **链接：** [论文](https://arxiv.org/abs/2608.11248)
* **核心内容：** EvoGraph-Mem 用可编辑 insight graph 维护长期 Agent 记忆，每个节点记录正证据、负证据与激活状态；执行后由 graph controller 保留可靠 insight、归档失效内容、修订过时经验并加入新知识。作者的跨 backbone 实验与消融表明 append-only memory 不足，而 evidence-aware retrieval 和图级编辑能改善可靠性与任务表现。
* **与你的方向关系：** 该工作连接 self-evolving agents、memory poisoning/污染与 evidence-guided harness update；其“负证据 + 状态切换 + 修订”机制尤其适合作为 code-as-memory 或失败窗口方法的结构化记忆对照。
* **建议：** **精读**。重点检查负证据如何归因、旧 insight 何时归档或重激活，以及 graph controller 会否通过错误反馈放大污染；摘要未给出具体增益数值，应以正文实验表为准。

## 7. An Empirical Study of Output-to-Input Loops for Black-Box Backdoor Detection in Fine-Tuned Open-Weight LLMs

* **类型 / 来源：** 新论文｜arXiv
* **作者 / 维护者：** Md. Nahid Hasan、Mohammad Arif Hossain
* **日期：** 2026-08-11
* **链接：** [论文](https://arxiv.org/abs/2608.11348)
* **核心内容：** 作者提出 self-feeding 黑盒检测：把模型输出连续反馈为下一轮输入，使文本从普通起始 prompt 漂移到微调数据中的隐藏触发分布。对六个 3B–15B、覆盖十一类后门的模型测试时，该方法以 92.0% pooled precision 检出其中五个；单个 prompt 的 recall 仅 19.2%，但多起点累计后模型级检出明显提高，四步链可在其实验中维持 100% 模型级 precision 并减少 60% 查询。
* **与你的方向关系：** 属于 LLM Security 与开源模型供应链安全，也与 Agent loop 风险相关：迭代上下文自身可能成为触发探索机制，可用于部署前低成本筛查下载模型。
* **建议：** **浏览**。重点关注后门类型与恶意输出识别器的覆盖边界；低单提示召回、一个完全漏检模型和两个 false positive 表明它适合作为 first-pass screening，而非安全证明。

## 8. Conformity Mitigations in Large Language Models Lie on a Single Resistance-Receptivity Frontier

* **类型 / 来源：** 新论文｜arXiv
* **作者 / 维护者：** Zafar Hussain、Kristoffer Nielbo
* **日期：** 2026-08-03
* **链接：** [论文](https://arxiv.org/abs/2608.11247)
* **核心内容：** 论文在 23 个开放模型、19 种条件和三个数据集上进行超过一百万次评分，测量错误多数意见如何覆盖模型原本正确的答案。六种缓解方法的 Resistance 提升通常以 Receptivity 下降为代价，均值落在 R² 为 0.80–0.90 的单一前沿；reflection 在 MMLU 上提高 7.9 点 Resistance，却损失 15.3 点 Receptivity。
* **与你的方向关系：** 与 multi-agent security 和语义信息传播直接相关：防止恶意或错误 peer influence 不能简单地让 Agent 拒绝一切外部信息，否则也会破坏正确协作；这为跨 Agent trust gate 提供了双目标评价。
* **建议：** **精读**。建议把 Resistance–Receptivity 前沿加入多 Agent 防御评测，重点核查错误多数构造、agent topology 与 reasoning 例外条件，避免只报告攻击阻断率而忽略有益信息接纳能力。

## 9. Harnessing Agent Memory to Build Lifelong AI Partners for Materials Scientists

* **类型 / 来源：** 新论文｜arXiv
* **作者 / 维护者：** Siyu Liu、Bo Hu、Beilin Ye、He Cao、David J. Srolovitz、Tongqi Wen
* **日期：** 2026-07-25
* **链接：** [论文](https://arxiv.org/abs/2608.11224)
* **核心内容：** 论文将材料科学经验保存为可检查事实与 executable skills，使失败边界、协议和验证规则可检索、修订并跨模型迁移。在 49 个真实工具使用问题的 138 个子任务上，记忆使 GPT-5.2 成功率接近翻倍；波函数初始化案例避免 92% 重复错误，13 个材料模拟工作流到第三轮时 token trace 负担减半、工具调用减少超过一半。
* **与你的方向关系：** 这是 code-as-memory、executable skill learning 与 self-evolving agent 的具体领域验证，展示失败经验如何编译为 pre-execution guardrail，并以较低 token 与工具成本跨轮复用。
* **建议：** **精读**。重点比较 inspectable facts 与 executable skills 的写入、修订和迁移机制，并检查减少轨迹成本是否来自任务重复度、记忆命中或真正可泛化的控制逻辑。
